# Darknes Tor 1.5 Beta — Futuristic redesign

This branch contains the visual refresh for the unreleased 1.5 Beta. It is not a release announcement.

## Visual direction
- Deep obsidian / midnight-blue surfaces.
- Layered glass panels with subtle translucent borders.
- Cyan-to-violet luminous accents, restrained bloom and metallic highlights.
- Rounded, carefully spaced controls with clear hierarchy.
- Rich, detailed artwork rather than placeholder squares or flat tiles.

## Scope
1. Replace the launcher icon with the new metallic orbital Darknes mark.
2. Redesign the home screen and search/address field.
3. Restyle tab overview, bottom navigation, menus, settings, security and account panels.
4. Add consistent transitions and touch feedback.
5. Preserve GeckoView, bookmarks, history, downloads, private tabs, Darknes ID and tester tools.
6. Build and verify the APK before calling the beta ready.

## Version
Display name: **Darknes Tor 1.5 Beta**  
Do not append “Release” to the in-app version name or branding before an actual release.
