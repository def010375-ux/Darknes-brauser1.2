# Darknes Tor — исправленная структура Android-проекта

Это стартовый Android-проект на Kotlin, Jetpack Compose и GeckoView.

## Сборка APK
1. Загрузите содержимое архива в корень GitHub-репозитория, сохранив папки.
2. Откройте вкладку Actions.
3. Запустите `Build Darknes Tor APK`.
4. После успешной сборки скачайте артефакт `Darknes-Tor-debug-APK`.

APK будет debug-сборкой для тестирования, не релизом для Google Play.

## Важно
Это только стартовый каркас браузера. Реальные учётные записи Darknes ID, сервер Darknes AI, полноценные вкладки, история, закладки, загрузки, расширения и приватный профиль ещё не реализованы.
