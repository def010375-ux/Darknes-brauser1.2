# Darknes Tor — Android starter 0.1.0

Это **стартовый Android-проект**, а не готовый полноценный браузер и не готовый APK. В проекте есть Kotlin + Jetpack Compose, встроенный GeckoView, адресная строка и базовая оболочка интерфейса.

## Структура проекта

```text
DarknesTor_Android_Starter/
├── .github/workflows/build-apk.yml
├── app/
│   ├── build.gradle.kts
│   └── src/main/
│       ├── AndroidManifest.xml
│       └── java/com/darknes/tor/MainActivity.kt
├── build.gradle.kts
├── gradle.properties
└── settings.gradle.kts
```

## Как получить APK через GitHub

1. Распакуйте ZIP.
2. Загрузите **содержимое папки** `DarknesTor_Android_Starter` в корень своего репозитория GitHub, сохранив все папки и вложенные пути. Не загружайте ZIP как единственный файл.
3. Проверьте, что workflow находится по пути `.github/workflows/build-apk.yml`.
4. Откройте вкладку **Actions** в GitHub и выберите **Build Darknes Tor APK**.
5. Дождитесь зелёного статуса успешной сборки.
6. Откройте завершённый запуск и скачайте артефакт **Darknes-Tor-debug-APK**. Внутри ZIP-артефакта будет `app-debug.apk`.

Если в репозитории уже есть файлы с такими же путями, замените их версиями из этого проекта. Не удаляйте другие нужные файлы, пока не проверили их назначение.

## Локальная сборка

Откройте папку проекта в Android Studio с установленным JDK 17 и Android SDK 35, дождитесь Gradle Sync и выполните задачу `:app:assembleDebug`.

## Текущие возможности и ограничения

- Android-приложение на Kotlin + Jetpack Compose.
- GeckoView как движок отображения веб-страниц.
- Адресная строка: URL или поиск Google.
- Начальный экран и информационная панель Darknes AI.
- GitHub Actions для сборки debug APK.

Пока **не реализованы**: серверная регистрация Darknes ID, собственный сервер/модель Darknes AI, полноценная система вкладок, история, закладки, загрузки, отдельный приватный профиль инкогнито, установка и управление WebExtensions, выбор Google/Яндекс и синхронизация между устройствами. Кнопки и экраны-заготовки не следует считать работающими функциями.

## Darknes ID и безопасность

Darknes ID задуман как единая учётная запись экосистемы Darknes. Для реальной регистрации нужен отдельный HTTPS backend и база данных. Не помещайте пароли, приватные ключи или секретные API-ключи в APK или GitHub-репозиторий.

В проекте нет VPN или Tor-маршрутизации, и он не обещает обход сетевых ограничений. Не отключайте TLS-проверку и не разрешайте произвольный HTTP-трафик.

**Параметры:** пакет `com.darknes.tor`, minSdk 26 (Android 8.0), compileSdk 35, Java 17.
